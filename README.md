# Game-Mobile-Pense-Bem
1 ano e meio depois eu retorno com uma nova versão do jogo “Pense Bem”, o projeto recria a experiência de perguntas e respostas em formato de app. Baseado no livro Walt Disney World e Epcot Center, traz questões sobre a Disney. Possui pontuações por acertos e erros, total ao final e interface mais moderna.
